# cotizacion

Sample single-page commercial quote (hero, module breakdown, price summary, payment step, FAQ). Open `/cotizacion/` on the static site.

Sample data only: client and company names are placeholders, prices read `$[PRECIO]`, the contact number is `570000000000`, and the payment keys are `REPLACE_ME`. The payment button shows a demo alert until you set a real provider key. Never put an integrity secret in the browser: compute it on a server.

Ported from `Monoga2025/cotizacion-william` (page and `media_dashboard.jpg`; shared `bg_desk_papers.jpg` already existed). Client-specific assets were not ported.
