# Grupo Monoga Home

Marketing site for a small software studio that builds admin panels, custom web systems and AI agents for small businesses. Static HTML with Tailwind (CDN) and a few vanilla JavaScript interactions.

## Pages

- `index.html`: landing page with the value proposition and calls to action.
- `soluciones.html`: service and solution overview.
- `agentes-ia.html`: AI agent services.
- `casos-de-exito.html`: case studies.
- `contacto.html`: contact page with a WhatsApp link and a form-style CTA.
- `guia-ventas-monoga.html`: sales guide page.

Each page also exists as `<name>/index.html` so clean URLs work on static hosts.

## Stack

- HTML5, Tailwind CSS (CDN), vanilla JavaScript, `canvas-confetti` (CDN).

## Run it

```bash
npx serve .
```

## Honest status

- Static site, no build step and no tests.
- Business contact numbers were replaced with the placeholder `570000000000`. Set your real WhatsApp number before deploying.
